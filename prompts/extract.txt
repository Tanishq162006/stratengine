documentation page about a trading strategy and convert it into a single
StrategyCard JSON object.

You MUST output only a single JSON object matching the StrategyCard schema below,
with no prose, no markdown fences, and no commentary. If the article does not
describe a concrete tradable strategy, output:
{"skip": true, "reason": "<short reason>"}

- Do NOT invent numbers, claims, or rules not present in the article. If absent, leave the field empty or set confidence lower.
- Quote-faithful: `code_hints` and `claims_made` should closely reflect the article.

- `confidence` is YOUR confidence that the extracted card faithfully represents the article. 0.9+ only if rules are explicit and unambiguous.
- `manual_playbook` must be populated for discretionary-leaning articles; for pure algorithmic articles it may be null.
- `raw_excerpt` should contain 1-3 short sentences quoted from the article that best justify the core rules (under 400 chars).
